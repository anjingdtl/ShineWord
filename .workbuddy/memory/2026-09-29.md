## 按 1M 大模型重新设计全量构建（方案文档产出）

用户决策方向：全量构建目标模型按 1M 上下文重新设计。产出 `docs/Shine-TRPG_1M_RESIDENT_BUILD_PLAN.md`（全书驻留构建方案）。

### 关键设计结论（后续施工依据）
- 现状三硬缺陷：① planner 只按输入窗口打包，1M 模型下 64 chunk/组 + 8k 输出 → 必截断、对半拆分 thrash；② `profileModelBudget.ts` 把输出硬钳 `DEFAULT_GROUP_MAX_OUTPUT_TOKENS=8000`；③ 请求结构无 prefix-cache 意识，全书 prefill 重复付费。
- 核心洞察：输入总量（全书一遍）与输出总量（~60-80 万 token/100 万字）都是不变量；1M 买的是**全书视野**（实体/技能/时间线一致性）+ **缓存经济性**（prefill 只付一次）。输出 token 决定 decode 地板（~100 tok/s 单流 ≈ 2h）→ **并发是必需品**。
- 方案：resident 模式（全书装下时：system+正文做字节稳定前缀，第三条消息带范围指令，逐范围抽取，N worker 并发）；装不下走 windowed（修复后的输出预算打包）。四段流水线：Pass0 全书实体注册表 → Pass1 范围抽取 → Pass2 全书规则映射（顺带解问题 1 的 800 facts 上限）→ Pass3 时间线。本地权威不变式全保留。
- 打包器 v2：chunksPerGroup 按输出预算反推，estOutputPerChunk 用 usageJson 在线校准；capabilities probe 补 `cached_tokens` 探测自动判定缓存支持，不支持则 resident 自动退化 windowed。
- 待用户拍板：D1 provider 组合 / D2 输出档（建议 16k）/ D3 缓存 TTL 续建成本（建议接受并 UI 明示）/ D4 与问题 1 的 P0/P1 合并排期（建议同里程碑）。

## 最终建设方案定稿 + 推送（2026-09-29 晚）

用户拍板：按 **DeepSeek V4.1 Flash + GLM-5.3-Flash** 双基线定稿，并要求把**思维链占用上下文/输出额度**纳入预算模型。产出 `docs/Shine-TRPG_1M_RESIDENT_BUILD_PLAN.md` 最终版，已提交并推送 main：`b64c406`（父提交 8d1efb0，FF）。

### 两模型关键规格（2026-09-29 检索，施工前以官方文档复核）
- DeepSeek V4.1 Flash：1M 上下文；最大输出 393K（部分网关 131K）；**思考可关**（双模）；缓存读 $0.003-0.007/M（近免费）；in $0.15-0.30 / out $0.60-1.20（峰谷 2×）；~230 tok/s。
- GLM-5.3-Flash：1M；最大输出 128K **含思维链**（最大思维链 131,072）；**思考不可关**，reasoning_effort low/high/max 默认 max，需 `thinking.clear_thinking:false`；缓存命中 ¥0.23/M（百炼）；in ¥0.8 / out ¥2.8；FlashX 200 tok/s；百炼 RPM 200 / TPM 3M。

### 定稿新增的核心设计（相对草案）
- **思维链预算模型**：ModelBudget 拆出 maxContentOutputTokens（默认 16,384）+ reasoningReserveTokens（GLM low 档初始 2,048，用 `reasoning_tokens` 实测校准；DeepSeek non-thinking=0）+ reasoningEffort 透传（抽取 off/low，映射/时间线 high）。打包公式三扣减：bodyBudget = contextWindow − maxContentOutput − reasoningReserve − reserve − overhead。
- **GLM 专属护栏**：max_tokens = 内容预算 + 思维链预留；距 131,072 上限留 8K 安全边际；`reasoning_only` 截断分支改为**先升预留重试一次再对半拆分**（避免低思考档无效拆分）。
- **缓存经济账修正**：resident 每单元重读全书 ≈ N×1M cached tokens——DeepSeek 近免费，GLM 约 ¥5-12/次（为全书视野付费，可接受）。费用主体仍是输出 token（~70 万/100 万字），与方案无关。
- **模型分工**：Pass1 抽取 = DeepSeek non-thinking / GLM low；Pass0/2/3（注册表/全书规则映射/时间线）= 高档思考。全量构建估算：DeepSeek $0.7-1.3 / GLM ¥8-9，12-20 分钟（并发 3）。
