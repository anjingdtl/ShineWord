# Android 真实用户验收计划（2026-10-01）

## 范围与执行约定

针对当前项目代码打包 debug APK，在本机 Android 模拟器上按真实用户操作验收。
真实模型配置读取用户指定的 `GLM-TEST.txt`，原著使用用户指定的完整《白篱梦》（希行）TXT。
凭据、小说全文、设备数据库和未脱敏请求只保留在忽略的本地目录；报告记录操作结果、错误类别、耗时和证据路径。
使用独立 Git 分支；每个模块在测试、修复和复测完成后提交一次，未经过设备验证的项目不能标为通过。
设备使用已有专用 QA AVD 的临时只读实例，避免修改原 AVD 的持久数据。

## 故障处理

每个阻滞先保存 UI 树、截图、相关日志和数据库状态，形成最小复现；定位代码并修复。
对业务正确性、恢复或防重复请求的修复增加针对性回归；界面轻微可逆变化以实际设备复测验证。
修复后重跑当前步骤及受影响的上下游流程，模块验收记录包含失败→修复→复测链路。
真实请求可能需要较长等待，以持久化账本和任务状态判断进展，避免盲目重复触发计费请求。
