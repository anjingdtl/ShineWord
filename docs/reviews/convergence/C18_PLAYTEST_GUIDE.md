# C-18 外部试玩指引（待真人执行）

> 目的：由真人对比「本地基线开局（V1.1.1+ 默认）」与「AI 定制主线（较慢）」的开始故事体感，并验证离线可玩性。执行人：用户/受邀玩家。施工 agent 不代替真人试玩（证据红线）。

## 准备（5 分钟）

1. 安装正式包：`dist/apk/release/ShineWord-V1.1.0-release.apk`（或 GitHub Release v1.1.0 附件），或后续包含 W4c 的版本。V1.0.0+ 可原地升级，旧项目保留。
2. 首启 →「我的」→ 配置 API（MiniMax M3.1 Flash 预设 / GLM / DeepSeek 任一；测试密钥向用户索取，只入 Keychain）。
3. 书库 →「＋ 导入小说」→ 选择一份 TXT（建议 2–10 MB 长篇）→ 等构建完成（约 1–3 分钟，含一次事实审查交互：对照原文选「按补充事实保留」或「转为待核实」）。

## 试玩任务单（约 15 分钟）

| # | 操作 | 观察点（请按体感打 1–5 分并记一句原因） |
|---|---|---|
| 1 | 世界页 →「开始冒险」→ 快速填身份 →「开始故事」 | **本地基线**：点击到进入游玩页要几秒？是否感觉"秒开"？主线卡是否写明"本地基线，后续由 AI 补全"？ |
| 2 | 游玩页连点 3 个"提交这一步"（本地建议） | 每回合多久出结果？叙事是否标注"（本地叙事）"？可接受吗？ |
| 3 | 确认页/向导高级入口 →「AI 定制主线（较慢）」 | 等待时长体感？提案卡内容 vs 本地基线的差异？ |
| 4 | 打开飞行模式，继续点 2–3 个本地建议 | 是否还能正常游玩？叙事是否显示本地模板？（W4c：离线不进死路） |
| 5 | 关飞行模式，主线面板看"后续主线准备" | 后台补全是否无感完成？ |
| 6 | 自由输入一句自己的行动（如"我去北坡矿区看看"） | 是否被合理绑定到建议路径或走 Planner？延迟可接受吗？ |

## 记录方式

- 直接在本文档末尾追加「试玩记录」小节（日期/设备/机型/各项打分与一句话），或口述由 agent 代记。
- 截图可选：开始故事点击前后的秒表截图、飞行模式下的游玩页。

## 已知边界（避免误报）

- 本地基线的开局主线是**模板**（这是设计取舍，AI 在后台补全个性化）。
- 离线时新回合的叙事是本地模板；已提交回合不受影响。
- 设备为真机时性能数据与模拟器数据不可比，请如实标注机型。
