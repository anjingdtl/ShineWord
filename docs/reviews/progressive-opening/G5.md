# Progressive opening G5: preparation feedback and optional full refinement

**Date:** 2026-09-29 (Asia/Shanghai)
**Implementation status:** complete, reviewed, and regression-checked.
**Product acceptance:** limited-scope release verified; real-source TTFP and full on-device gameplay remain blocked by the tested model response and the lack of a ready campaign fixture.

## Implementation

- The world overview now reports each book as **已整理 / 未整理 / 未发现**. Status is computed from the exact published package, source citations, extracted facts, and chunk checkpoints. For a campaign it uses the locked package, active branch deltas, discovery state, and story-time anchor; hidden GM, undiscovered, and future material does not contribute to the player-facing book projection.
- **未发现** is scoped language: while full-source completion is false, the UI says that the opening range had no visible hit and unorganized source remains unknown. A book is described as absent from the whole source only after a `full / whole_source / complete` package, complete extracted chunks, continuous whole-source coverage, and local source length all agree.
- Added a user-triggered **可选：全量精编三宝书** action. It is never started by opening import. It uses the saved profile's model budget, reuses/resumes eligible extraction runs, avoids resuming a run owned by another model profile, and continues to use the normal world-package publish gate. Mapping and publication run inside the coordinator's renewable lease; a canceled late mapping response is discarded before package publication.
- Full-source scope uses at most 64 contiguous hashed ranges. Reads are grouped from the local shard store; only whitespace may fall between extractor chunks. The provided《白篱梦》source parsed to 944 chunks with nine one-code-point whitespace separators, producing 63 coverage ranges from code point 0 through 965,458 without loading the entire stream for the package manifest.
- The world detail screen shows persisted background task progress and the latest package revision. A campaign continues to use its frozen base package; a later full package is available to new campaigns. The player book projection includes the branch content manifest and immutable deltas, filtered at the campaign's story-time anchor.
- No schema migration was needed for G5. G4's `world-package-3` scope and `shineword-save-6` branch content remain the persisted formats; legacy package and save readers are unchanged.

## Review fixes

- Review of the supplied source found that serializing one coverage range per chunk would exceed the package/archive limit of 64, and that nine parser gaps needed explicit treatment. Added bounded range grouping and a whitespace-only gap check. Any non-whitespace gap, overlap, incomplete chunk, hash/range mismatch, or missing source length blocks full publication and leaves the already-published opening package in place.
- Full completion status now checks continuous whole-source coordinates and that all extracted chunks are covered by the package scope. It does not infer completion from an LLM HTTP 200, the number of calls, or a package label alone.
- Player-facing preparation copy describes only the filtered view, even after full-source extraction. It does not label hidden, undiscovered, or future content as absent from the novel, and does not say opening-only material remains unorganized after a full package is published.
- The manual refine path no longer resumes a `needs_review` run as if it were runnable and rejects a conflicting active model fingerprint instead of starting duplicate work.
- Initial Gradle Release attempts hit a Windows/JDK loopback IPC failure. Setting the build process temporary directory to `C:\tmp` allowed the same signed Release build to complete; no project signing or source settings were changed for the workaround.

## Limits and acceptance gate

- The endpoint evidence in [G0](G0.md) and [G1](G1.md) contains no complete dossier for the supplied novel. The 8,000-code-point probe with a 4,096-token output cap took 57.508 seconds and ended with `length` after 4,050 reasoning tokens and zero business-text characters; the 8,000-token-cap attempt timed out at 120.024 seconds without dossier text. Reasoning policy was not changed. The current profile therefore cannot demonstrate the ≤60-second median / ≤120-second P95 TTFP target, and no actual 《白篱梦》 first playable turn is claimed.
- The Android check covers Release install, launch, and hierarchy capture only. It does not claim an end-to-end TXT import, character creation, first turn, first-ten-turn wait, full refinement, lock-screen/background recovery, offline resume, or a real-device run.
- Existing regression tests cover package publication, campaign package locking, branch/save/archive/fork/rewind consistency, future/secret visibility filters, G3 request bounds and cache invalidation, lease renewal, cancellation, and old-format migration. Those test results are not substitutes for the outstanding on-device scenarios.
- Progressive lookup remains source-citation bounded. An unknown local match does not establish that a fact is absent, and arbitrary unseen chapters are not presented as reviewed facts. The delivery is a playable opening-scope implementation plus optional full-source refinement, not a claim that unrestricted exploration of the entire novel is complete.
