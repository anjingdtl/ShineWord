## 安全与兼容复核

- 没有修改 `applicationId=com.shineword.app`、规则集、骰点/成长、固定合同、RollRecord、既有包内容、密钥存储实现或旧存档读取路径。
- 开局仍经正常 publish validator；`needs_review` 仍是 review；部分范围包不冒充全书完成。
- 主动查书只会写入逐字原文 `discoverable lore`，并逐章重读核对范围与哈希。它不会生成规则数值或总结；未确认条目被玩家投影和 Planner 隔离。
- 没有用 `pm clear`、`adb install -r` 以外的重置方式、`-wipe-data` 或脚本删除数据库。没有生成包含原文的截图。测试 key 只经 app profile 存入 Android Keychain；探针 JSON 仅存脱敏计时/usage/结构校验数据，没有 source、response、Authorization 或 key。
- Release APK 构建脚本验证了配置证书、单签名者、v2 签名及 zip 对齐。Gradle 的 `TEMP/TMP=C:\tmp` 仅用于这次构建进程。

## 未达目标与后续门禁

《白篱梦》TTFP 中位数 ≤60 秒、P95 ≤120 秒**未测且无达标证据**。完整 dossier 的一次成功探针本身用了 88.281 秒；Release 真实请求则在发布前失败。因此不能从输入缩短比例、首次目录/角色页或夹具性能推算可玩时延。P95 也不能从一次请求推导。

前十回合累计扩充等待、端上全源索引 P50/P95、长距离探索、真实来源标注召回、活动任务在锁屏/杀进程后的恢复，以及 Android 上的存档导入/导出/fork/rewind 全流程，需要一个在该输出预算下能返回可验证 dossier 的端点配置和后续设备验收。本交付的产品边界是**范围受限的开局 + 玩家主动本地查书 + 可选全量精编**，不是“全书自由探索已全部完成”。
