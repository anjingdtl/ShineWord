## 一票否决项核查

- 世界事实冲突：无（canon 冲突在构建审查层解决，旅程内无编造原著事实进入权威状态）。
- 重大泄漏：无（公开提案不含 gmPremise；A33 单测 + 旅程公开字段抽查）。
- 强制回滚合法结果：无（所有拒绝均发生在编译/资格层，已提交结果从未回滚）。

## 内容质量与真实模型的典型漂移清单（工程修复记录）

真实 GLM 在 campaign_plan 任务上的结构漂移及本地容错（全部在严格门禁内）：
1. 方法目标字段名（goal/description/firstStep.description 三态）；
2. firstStep 为字符串 / {skill(s)} / 完整对象三态；
3. outcomes 为按档对象 / {tier|level|grade} 数组两态；
4. situation_status 使用自造状态值 → 转计数器；
5. 条件字段别名（situation/quest/event/counter/minimum/count/value）；
6. next 数组混入散文注记 → 仅保留 ID 形态引用；
7. 阻断型 constraint → 降级 audit + 审查问题（世界层修复）；
8. 悬空战利品引用 → 丢弃 + 审查问题（世界层修复）；
9. 开局即成立的结局 → 采用期拒绝（旅程发现的真缺陷，已修复并单测化路径）。

以上容错均先以**已保存真实响应离线 100% 重解析**为门（18/20 通过；2 份为修复前历史样本），再消耗真实请求。
