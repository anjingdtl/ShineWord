# 本地性能与可访问性证据

## A40 本地确定性压力

自动化生成的结果存放于 A40_LOCAL_PERFORMANCE.json，类型为 production-session-local-deterministic，走生产 Session 和本地确定性 provider。结果摘要：

| 合成决定数 | stateVersion | 快照 bytes | Runtime bytes | 查询 ms | 总耗时 ms | 合成 provider calls |
|---:|---:|---:|---:|---:|---:|---:|
| 100 | 100 | 5128 | 1414 | 1.0614 | 1579.8884 | 200 |
| 300 | 300 | 5129 | 1414 | 2.1528 | 4876.5335 | 600 |
| 1000 | 1000 | 5133 | 1415 | 7.0907 | 29251.1430 | 2000 |

这是本地合成状态压力回归，不是有效玩家决定、真实模型请求或正式旅程。合成 provider calls 不是物理 HTTP 请求；本轮物理模型请求为 0。A40 的本地确定性合同通过。

该样本未记录匹配模型/推理/设备/材料/起点的基线与最终性能，不能支持真实性能提升或回归结论，也不替代 10+10 的配对性能样本。

## UI 可访问性与小屏冒烟

API 37 隔离 AVD 在临时 720×1600、320dpi（逻辑 360×800dp）视口下显示完整合成回合结果卡：行动、结果、耗时、骰值与故事均可读；下一段局势内容部分位于固定输入栏之后，未据单张截图判定为缺陷。小屏截图见 `R8-small-screen-turn-top.png`。

启用 TalkBack 后检查了当前页面的焦点框和节点语义，关键字段及交互控件可被访问；证据截图为 `R8-talkback-focus-1.png`。没有完成逐项语音播报/焦点顺序验收，也没有由无障碍用户参与。TalkBack 和屏幕覆盖设置均在测试后恢复原状。

R8 保持 PARTIAL；A40 为本地合成压力 PASS；A35 为 UI 冒烟 PARTIAL；A37 的真实配对性能 BLOCKED。主题对比、状态颜色冗余、API 24、实体机、正式玩法路径和完整可访问性均未验。

## 本轮 Android 性能/可访问性范围

本轮没有采集Perfetto、CPU、内存增长、掉帧、启动时长或匹配模型性能数据；AVD有约3GB RAM且为API37 x86_64。合成回合仅用于状态与回放集成。完整TalkBack、主题和实体机仍未验证；小屏只测试了360×800dp一个视口。A40数据仅复制自上一轮相同production-session-local-deterministic结果，未在本轮重跑。
