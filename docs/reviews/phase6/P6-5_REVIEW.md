## 真实观测与结论边界

用户授权 UTF-8 小说 7,178,905 字节，规范化 3,460,333 码点、1504 章。用户提供 GLM 测试端点，low。新本地项目一次请求导入 9.142 秒、抽取与发布 42.859 秒、TTFP **52.046 秒**，29 facts / 6 events / 1 artifact。HTTP 200 时长 41.547 秒、5064 input / 2995 output tokens；其中 cached input 5056。因此是本地新建、服务端热缓存，当前最终策略 n=1。不能宣称稳定 90 秒、全冷加速或真机性能。

更早样本有事实不足、地点解析、依赖和身份冲突的真实阻断；已有响应本地适配后成功必须与全新成功分开。已有修复开局进行两次真实 Planner/Narrator 回合成功。最终开局第一后段 1200 码点成功发布并采用（74.368 秒，1 次抽取、2 次映射，首次映射 JSON 失败仍有计费）；第二后段抽取完成，映射触及自设请求上限，未得到第三个成果。该处账本保留 unknown，不自动重发，不计为第二次成功采用。

风格三模式本地编译与快照有测试；真实分析成功。没有人工标注，因此叙述自然度、原著风格还原程度与连续内容质量尚未完成验收。凭据、小说正文、响应和 SQLite 留在私有 scratch；仓库仅收脱敏计数与时长，见 MEASUREMENTS.json。
