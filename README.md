# ShineWord

面向 Android 的 AI 互动小说跑团应用。

导入小说 TXT，构建有原文依据的世界，扮演原著角色或原创角色，通过选项与自由行动探索自己的故事。LLM 负责主持与叙事，本地规则引擎负责能力约束、掷骰、成长与状态结算。

> 当前状态：建设规划阶段，尚未提供可运行 App 或 APK。

## 建设方案

请阅读 [ShineWord 完整建设方案](docs/SHINEWORD_IMPLEMENTATION_PLAN.md)。方案包含项目调研、tavo-mini 复用边界、世界构建、骰池规则、角色成长、回合状态机、LLM 协议、数据库与分支存档、安卓实现、里程碑和验收标准。

## 核心原则

- 仅 Android，本地优先，用户自行配置模型 API。
- 原著规则与开局历史保持一致，未来事件可以合理分叉。
- 掷骰前锁定条件与风险，LLM 不改写骰点和机械结果。
- 状态、事件与叙事分离，支持保存、恢复和分支。
